Code builds the game, AI renders the world in real time

A game engine keeps the world state and draws a cheap low-poly proxy. A VLM decides whatever the rules cannot. A few-step causal video model turns every chunk into a finished frame on a single consumer GPU.

OVERVIEWA harness around the video model

Interactive world models that only roll out pixels keep the world state implicit: once something leaves the view it is gone, and game rules have to be re-inferred from every frame. We wrap the video model in a harness that owns the state. The game engine evolves everything the rules can decide and renders it as a low-poly proxy. The VLM takes over where rules run out: it turns states into prompts, reasons about how the world should evolve, and registers its decisions back into the engine.

The video model then only has to render. It reads the per-frame proxy, a dynamic caption and a few reference frames, and generates one latent (four frames) per step with a causal DiT distilled to one or two denoising steps.

METHODHow it works

Rolling KV cache, one chunk at a time

Each new chunk attends to retrieved spatial memory, the reference frames and a sliding window of recent chunks. The oldest chunk leaves the window as a new one arrives.
